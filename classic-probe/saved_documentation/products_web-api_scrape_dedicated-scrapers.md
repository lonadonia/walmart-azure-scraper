# Dedicated Scrapers

Discover Oxylabs Web API dedicated scrapers for structured field extraction from specialized web targets.

Beyond the generic [`/scrape`](/products/web-api/scrape.md) scraper, Web API offers purpose-built and actively maintained scrapers for specific targets:

```http
POST /v1/scrape/{target}/{collection}
```

The **generic scraper hands you the whole page**, while a **dedicated scraper hands you the fields** on that page, such as product price and availability, a SERP's organic positions and ads, a video's duration and view count, etc. Results are parsed and named, with the parser maintained by Oxylabs when the site's markup changes.

{% hint style="success" %}
This page covers the basics across targets and their specialized endpoints. To get an up-to-date dedicated scrapers list and and their parameters, use [Endpoint Discovery](/products/web-api/scrape/endpoint-discovery.md). A reference endpoint and parameter tables are found in the [**API Reference**](/api-reference/overview.md).
{% endhint %}

## Which endpoint to call

Each endpoint takes either a `query` or a `url` (not both):

</code></pre><p>Identifier or search term (e.g., ASIN on <code>/amazon/product</code>, a keyword on <code>/amazon/search</code>, a video ID on <code>/youtube/metadata</code>, etc.). Most dedicated scrapers exist in two variants:

* `/v1/scrape/...` returns the result in the response (sync/realtime)
* `/v1/async/scrape/...` returns a job and accepts `callback_url` (async)

A few of the dedicated scrapers run only as jobs, some also support batch of values. Learn more in [Delivery Modes](/products/web-api/scrape/delivery-modes.md).
