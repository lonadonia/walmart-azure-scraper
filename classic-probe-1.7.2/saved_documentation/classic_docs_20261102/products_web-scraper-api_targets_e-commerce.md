# E-Commerce

Find Oxylabs Web Scraper API scraping guides for most popular global e-commerce targets.

The table below lists every e-commerce source, whether it has a dedicated parser, and which target-specific localization parameters it accepts. Click a target to open its page with request samples, parameters and output. The values and rules of each parameter are in the **Localization and Filtering** section of the target's page.

{% hint style="info" %}
**Any page can be scraped by passing its `url` alone, no `source` needed.** The sources below are for search, product and category pages with target-specific parameters and, where available, a dedicated parser.
{% endhint %}

{% hint style="warning" %}
For some targets our system **forces JavaScript rendering** even if you do not set `render`; those requests count as rendered traffic. The list of force-rendered targets and how to switch rendering off are in [Forcing rendering on specific pages](/products/web-scraper-api/features/js-rendering-and-browser-control.md#forcing-rendering-on-specific-pages).
{% endhint %}
